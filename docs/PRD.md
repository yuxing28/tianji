# 天机 PRD v0.1（MVP）

## 1. 背景与机会

X 帖子（@0xGky，2026-11-06）盘点了 6 个高热度玄学 AI Skill 仓库（合计 6k+ stars）：奇门遁甲/紫微、八字、姻缘、佛学、风水、塔罗。它们证明了需求存在，但形态都是"装进 Claude Code 的技能"，普通用户用不上。
现有网页竞品（如 openfate.ai）只做八字单点。**把四件套做成一个安卓 App = 把 Agent 时代的玄学能力带给普通手机用户。**

## 2. 目标用户与场景

- 18–35 岁泛娱乐用户；场景：娱乐猎奇、社交分享、自我探索、"决策安慰剂"
- 核心诉求：快（10 秒出结果）、准（排盘确定性好，不瞎编）、有氛围感（值得截图分享）

## 3. 产品原则（继承自源仓库的设计哲学）

1. **先追问，再输出**：信息不全（如缺时辰）时先引导补全，不强行排盘
2. **确定性计算外包**：排盘/抽牌/飞星由本地引擎算，LLM 只做解读 —— 这是可靠性关键（推文评论区实测：同一生日问 Gemini 六次日柱出现五种答案，接引擎可根治）
3. **口径透明**：显示所用流派与换日规则
4. **只给结构化参考**：不替代医疗/法律/财务建议；不制造焦虑、不恐吓；自伤信号出现时展示心理援助转介文案

## 4. 信息架构

底部 5 Tab：**今日 · 八字 · 姻缘 · 塔罗 · 风水**；设置（LLM Key、免责声明、关于）= 今日页右上角齿轮。

## 5. 模块规格（v0.1）

| 模块 | 输入 | 本地计算 | LLM 解读 |
|---|---|---|---|
| 今日 | 无 | 每日签句 + 黄历摘要 | 每日一言 |
| 八字 | 阳历/农历生日 + 时辰 + 性别 | 四柱、五行、十神、大运流年（移植 bazi-skill `pai_pan.py`） | 日主强弱、格局、事业感情建议（注入九本古籍摘要） |
| 姻缘 | v1 两式：① 八字合婚（双方信息）② 求签问姻缘（摇签筒抽 100 签） | 合婚打分 / 抽签 | 合婚报告 / 签诗解签 |
| 塔罗 | 问题 + 选牌阵（单张 / 三张 / 凯尔特十字） | 抽牌动画 + 正逆位（移植 tarot-skill `draw.py` 逻辑） | 牌义 + 牌阵叙事（注入 78 牌义库） |
| 风水 | 朝向 + 入住年份 + 户型要点 | 玄空飞星盘 + 八宅吉凶位（移植 fengshui 计算包核心） | 旺位凶位与布局建议（注入飞星/八宅规则） |

结果页统一结构：排盘/牌面可视化 → 结论金句（金色）→ 分维度解读卡片 → "仅供娱乐参考"脚注 → 分享/重新测。

## 6. LLM 接入

- 设置页配置 **OpenAI 兼容端点 + API Key + 模型名**（本地存储）
- 解读请求 = 模块知识库（源仓库 references 精简版，随 APK 打包）+ 排盘结构化 JSON 作为上下文
- 无 Key：可完成计算看到排盘，解读区锁定并引导去配置
- 解读流式输出；失败重试 1 次；超时 60s

## 7. 非功能

- 免责声明：首次启动展示一次 + 每个结果页脚注
- 隐私：出生信息仅本地存储；LLM 请求仅发送计算所需最小字段
- 性能：排盘 < 100ms；LLM 流式首字 < 5s（取决于端点）

## 8. 版本规划

- **v0.1（本阶段）**：四件套主流程 + 今日页 + Key 配置 + 真机可用
- v0.2：历史记录、分享卡片、更多牌阵/姻缘模式
- v0.3：奇门遁甲、紫微斗数、佛学问答（Master-skill 需替换 CC BY-NC-SA 内容）
