# 天机 · Design System MASTER（v2 · 方案 A「墨」）

> 选定记录：2026-11-07，用户在 4 方案情绪板（spark-output/board/tianji-moodboard.html）中选定 **A 墨**。
> v1「紫微紫 + 鎏金」暗色玄学风因「过于花哨、不够简约现代」废弃。
> 完整 tokens：spark-output/context/board.json。

## 1. 基调

- **克制、暗色、单强调色、细线、大留白**——气质参考 Nothing OS 与纸墨
- 玄学氛围靠内容质感与动效表达，不靠颜色堆砌
- 定性：娱乐 / 文化学习产品，所有解读标注"仅供娱乐参考"

## 2. 色彩 Tokens

| Token | 值 | 用途 |
|---|---|---|
| `--color-background` | `#0C0D0F` | 全局近黑底 |
| `--color-surface` | `#16181B` | 卡片 / 面板 |
| `--color-surface-2` | `#1E2126` | 次级面板 / 输入框底 |
| `--color-foreground` | `#E8EAED` | 主文字 |
| `--color-muted-foreground` | `#9BA1A6` | 辅助文字 |
| `--color-primary` | `#8FC7CC` | 雾青：主操作、选中态、进度、强调 |
| `--color-on-primary` | `#0C0D0F` | 主色上的文字 |
| `--color-secondary` | `#3A3D42` | 次级结构色 |
| `--color-border` | `#232529` | 1px 细线 / 卡片描边 |
| `--color-destructive` | `#E5695E` | 删除 / 危险操作（柔红，不刺眼） |

对比度校验：`#E8EAED` on `#0C0D0F` ≈ 14.9:1 ✓；`#9BA1A6` on `#0C0D0F` ≈ 7.1:1 ✓；`#0C0D0F` on `#8FC7CC` ≈ 9.6:1 ✓ —— 全部 ≥ 4.5:1。

**禁用**：渐变按钮、辉光/发光效果、大面积彩色、第二强调色。

## 3. 字体

- 全局：**HarmonyOS Sans SC**（APK 内置，回退系统黑体）；数字与英文 **Inter**（`tabular-nums`）
- 气质表达方式：加大字重（500/600）+ 宽字距（0.02–0.04em）+ 大字号，**不用书法体**
- 层级：大标题 28–32 / 标题 20 / 正文 16 / 辅助 13（正文下限 12）

## 4. 布局与组件

- 底部导航 **5 Tab**：今日 · 八字 · 姻缘 · 塔罗 · 风水；设置 = 今日页右上角
- 卡片：`#16181B` 底 + 1px `#232529` 描边 + 圆角 12，**无阴影**
- 按钮：主 = 雾青实底深字（圆角 8）；次 = 透明底 + 1px 边框；触控 ≥ 44dp
- 输入框：`#1E2126` 底，聚焦态 1px `#4E8A90` 边框
- 标签：`#1E2126` 底 + `#C2E2E5` 字，圆角 4
- 图标：1.6px 线性 SVG（禁 emoji）
- 动效（motion 4/10，比 v1 更收）：淡入 + 轻位移 200–300ms；塔罗翻牌保留但去光效；`reduced-motion` 时直接渲染终态

## 5. 反模式（含 v1 教训）

- 紫金撞色、大面积渐变、辉光（v1 废弃原因）
- emoji 当图标、书法体标题滥用、多层阴影
- 恐吓式文案（"血光之灾"）；fengshui 仓库原则：不恐吓煞气
- 依赖 hover 的交互、文字 < 12sp
